# Cookie_Translator
Cookie Translator es una extensión de navegador que lee lo que declara el banner de cookies de una web y lo explica en lenguaje claro antes de que aceptes o rechaces. Te dice qué datos se recogen y para qué (GPS, perfiles para anuncios, vincular dispositivos…), ordenados de más a menos graves. Funciona en local, sin enviar nada a ningún servidor.
